# Frontend PDP - E-commerce Product Detail Page

A React + TypeScript implementation of a Product Detail Page (PDP) with add-to-cart functionality.

## Features

- Product Gallery with thumbnail navigation
- Color and Size variant selectors
- Quantity control with stock validation
- Add to Cart with success feedback
- Loading and Error states
- Responsive design for mobile

## Tech Stack

- React 18
- TypeScript
- Vite
- CSS

## Getting Started

```bash
cd frontend
npm install
npm run dev
```
